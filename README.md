## Deploy lên GitHub Pages
1. Tạo repo mới tên **MuaVang** (public) trên GitHub, không tick "Add a README".
2. Trong thư mục này chạy:
   ```bash
   git remote add origin https://github.com/<user>/MuaVang.git
   git push -u origin main
   ```
3. Vào **Settings → Pages**, Source: *Deploy from a branch*, Branch: `main` / `/ (root)`, Save.
4. Đợi ~1 phút, mở `https://<user>.github.io/MuaVang/`.

Sửa lịch trình: chỉnh `index.html`, commit, push lại là trang tự cập nhật.
